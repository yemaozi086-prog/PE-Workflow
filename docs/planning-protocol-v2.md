# 简化规划、有限子图与局部格式修正

## 本轮改变

智能体负责计算意图、物理声明和来源；程序负责构造冗余接口字段、精确复制引用、网格和循环子图。没有放松既有物理检查。新协议不会猜单位、轴、数组维数、采样长度或运行值。已登记模块仍冻结，未知工具仍须生成、核对后明确注册。

新任务使用 `plan_blueprint`：`blueprint.port_defs` 中定义接口一次，在 external_inputs 和 steps 的 inputs/outputs 中用 `{"ref":"名称"}` 引用。数组简写必须同时给出 type=array、dtype、shape、axis_names，例如：

```json
{"type":"array","quantity":"frequency","unit":"Hz","dtype":"float64","shape":["frequency_count"],"axis_names":["switching_frequency"]}
```

程序构造kind/value_type/axes；不会把frequency_count补成21。相同接口多个使用处不再让模型重抄完整Port。

## 第一版控制范围

- `grids`：显式输入字典来源、`axes`（输出字段→局部字典.字段）和独立的`axis_order`；只做有限一维数值轴笛卡尔积，最多1000行，拒绝空轴。轴顺序作为列表冻结，不依赖JSON对象键排序。
- `loops`：kind=batch、计算成员step_ids、rows来源、captures共享输入、outputs成员结果。程序从明确rows列声明构造item，从captures来源复制契约，并生成可展开body；各成员仅能看到item、captures与同子图上游。
- 允许多个单层有限控制节点，不支持嵌套或直到收敛。禁止跨子图直接连成员；外层只能使用控制节点输出。
- 控制节点由程序生成，不作为缺失模型要求用户注册。原始公式步骤仍是普通工具，代码生成并发与运行遍历是不同概念。

## 修正与等待

错误声明会保留原始冻结对象与哈希，给出allowed_paths。模型只能返回plan_delta，局部替换诊断允许的声明；禁止顺带改变单位、语义、必填性、默认值、已有明确维数或精度。公式、步骤和拓扑不在补丁范围。输入来源问题沿用PlanPatch；无法确定安全局部范围时暂停核对，不重写整份计划碰碰运气。模型修正继续消耗原额度，重复错误和额度耗尽仍停止。

进度区显示事件之间的耗时与独立的工具活动。调用经过时间不是“纯模型思考时间”；工具读取/心跳也不表示方案有实质进展。长等待提醒默认600秒，可在本轮进度区改为1–60分钟，或设置环境变量PE_DESIGN_WAIT_WARNING_SECONDS。达到阈值只提示检查或明确停止，不自动重发；旧有送达超时保护仍保留，不能将其当作已取消远端调用。

## 旧任务

旧任务不会自动迁移。页面“查看协议迁移清单”只读显示变化和剩余额度；确认后形成暂停的新修订，再明确使用剩余额度继续。耗尽或重复错误停止不能靠迁移绕过，需另行批准追加。原需求、原失败、候选与额度历史保持；不自动注册或运行。

## 验证证据与界限

- 全量后端回归377项通过；其后新增边界测试与本轮关键测试共11项通过。前端构建、输入与布局测试通过。
- 隔离API测试：提交简化方案、局部修正、确认工具、程序组装、保存、执行有限子图。
- 跨任务控制测试：电流网格铜损，输入[-2,0,2]和R=0.5，输出[2,0,2]；说明网格控制不包含LLC专用正电流假设。
- LLC核心验收：6工况×21频率，子图逐点计算增益、输出电压/功率、电流、电容交流应力、指定损耗及约束，与独立复数阻抗参考比对；收紧电流上限后所有点不合格，Cr=0停止。
- 上述LLC使用测试专用明确公式模块，不进入用户工具库，也不冒充DSH生成。最终分组报告/推荐工具以及真实DSH在新协议下完整生成、补工具、保存与运行的端到端预演，仍需用户确认迁移并批准必要调用后实测。

此次不承诺模型服务更快或固定几分钟完成；优化的是重复声明量与修正范围。真实速度收益应从新任务调用数、输出字符数和阶段耗时衡量。
