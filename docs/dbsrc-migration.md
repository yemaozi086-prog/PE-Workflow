# DBSRC EPS 单步迁移

权威源为用户指定的 `deep_agents-dev_WDY (1)/deep_agents-dev_WDY`，不是相邻 aeep-dsh 草稿。原始 25 个依赖文件的 SHA256、基准输入、完整矩阵和状态污染实验见 `dbsrc-reference.json`。其中 23 个计算依赖迁入 `backend/pe_workflow/science/dbsrc_v1`，只改静态包导入前缀；ENV 和 Excel 导出器不进入运行时。

## 计算链与循环

JSON：`examples/dbsrc/single-step.json`。22 个固定版本模块，所有计算输入输出均为独立命名的扁平字典。

1. 归一化动作裁剪及反归一化；计算谐振频率与频率偏移。
2. 遍历 7 个额定功率电压点，汇总器件电流/电压需求及滤波电容需求。
3. 分别进行变压器、电感、开关、谐振电容、输入/输出滤波电容选型。
4. 外层批量子图逐个计算 28 个电压/负载工况。
5. 每个工况生成至多 50 个 D1 移相候选；内层子图逐候选计算四种损耗，各有独立约束节点，随后计算效率。
6. 按原顺序选取最高可行效率；相等时保留第一个候选，输出原来的 9×4 详细矩阵。
7. 重建 7×4 效率矩阵与 7×4×9×4 详细矩阵；汇总体积、成本和加权效率；按原归一化、权重和裁剪生成奖励。不可行返回 `valid=0, reward=-1`。

原依赖闭包中未发现 `while` 循环。D1 扫描、器件数据库搜索和数值波形统计是有限计算，不能解释为 PPO 训练或物理收敛。将来的真实收敛循环需要显式初值、状态更新、残差、容差、最大次数及不收敛处理；本次没有实现通用 iterate 节点。

## 批量子图接口

画布、模块库、中文搜索和上传目标提示使用电力电子专业名称，例如“IGBT 导通与开关损耗计算”“高频变压器铜损、铁损与磁通密度计算”“谐振电容介质损耗计算”。22 个计算模块及两类遍历节点的展示名称定义在 `frontend/src/domainNames.ts`；用户自定义节点名称优先。技术 ID 和冻结模块名称/契约不被覆盖，避免仅改显示名称就破坏旧快照的哈希校验。

`kind=batch` 的 `body.inputs.item` 是一个数值扁平字典。外部 `rows` 将其每个字段加上相同第一维 `batch_rows`，其余输入保持独立并逐行共享。子图输出也按第一维堆叠。不自动重采样、转置或合并上游字典；字段轴和维度必须对应。单批最多 1000 行，单次最多 20000 节点步骤，仍受原工作进程超时控制。执行计划只在同一次运行内复用。

无候选时，内置模块产生一个显式 `valid=0` 的拒绝占位行，后续损耗节点跳过计算。固定数值契约中的填充值只用于传递拒绝状态，不能解释为零损耗有效结果。最终 `valid=0` 时效率/细节矩阵保留新建旧 ENV 的零初始状态；指标不能作为可行设计依据。

画布双击 `workpoints`，再双击 `modulations`，即可选中四个独立损耗模块及四个约束检查模块。DSH 替换一个损耗函数时，外围遍历和约束节点不随之替换。运行轨迹分为每页 200 步，完整数据仍可导出。重复执行的字段映射只保存首次完整声明，后续通过 `field_mappings_ref` 引用相应轨迹路径；实际输入输出仍逐步保留。界面运行及适配任务的计算进程预算为 60 秒。

## 信任与复现

复杂科学模型含类、循环、SciPy 插值及静态器件库，不属于用户单函数上传的受控语法。使用平台明确登记的 `trusted_builtin`，只允许内置清单中的精确模块声明，并核验科学代码与封装器哈希。JSON 不能指定任意导入路径或任意源码入口。源码或声明变化后，旧模块会拒绝执行；必须保留旧版本实现或发布新版本，不能静默回放成新代码。

用户/DSH 新候选使用 `python_function`，清除 `builtin_id/builtin_hash`，继续经过受控解释器、语义、样例与完整图验证。DSH 上下文中的大量循环样例只发送最多 12 个代表样例，全部基准轨迹仍保存在平台任务证据中。尚未进行本拓扑上的真实 DSH 上传替换验收，不能以此前电容示例的通过代替它。

## 刻意保留的旧行为

- 选型汇总会分别取某些电流指标的最小值；它们不一定来自同一个移相候选。本次保持原算法。
- 本次基准中谐振电容选型返回 None，旧 ENV 只拒绝 `{}`，因此继续计算；成本/体积缺失项按原指标工具记 0。适配器显式暴露 `available=0` 及原因，不声称已选出电容。
- 开关选型返回型号字符串，原指标计算器因此不计开关成本。变压器、电感默认选型也不提供成本字段。基准总成本 14 元不能作为完整实际 BOM 成本。
- 权重矩阵形状不符时原指标工具回退到均值；本首版固定 7×4 工况及默认权重，没有开放任意工况网格。
- 保留损耗和磁密约束的旧默认值；没有器件物理重新标定。
- Q55 明确排除跨 step 的历史状态污染；每次独立评价。此选择是已确认的执行语义，不是偷偷修正公式。

## 验证与范围

原 ENV 基准动作 `[-0.1638,0,-0.3891,-0.7529]`：奖励 `0.704378924970644`，加权效率 `0.9573093852587994`，体积 `198150`，成本约 `14`。比较完整效率和详细矩阵，不能只比较奖励。

本地部署 API 已保存 r1，运行与冻结快照回放均成功，两类矩阵最大绝对误差均为 0；证据见 `dbsrc-api-verification.json`。一轮完整运行记录 11688 步。后端全套 129 项回归通过；随后新增接口替换及轨迹引用回归，相关 50 项分别通过。前端生产构建通过。

`examples/dbsrc/alternate_capacitor.py` 是新的上传测试函数。开发回归通过显式适配器将它替换到内层 `loss_capacitor`，完整奖励与详细矩阵仍一致，独立电容约束节点未改变。该候选只用于测试，没有发布为用户工作流的新模块版本，也没有调用 DSH；以后真实 DSH 测试应上传原函数，由 DSH 自己生成适配器。

默认 EPS、默认动作范围、固定 7 个电压×4 个负载是本首版范围。Vin、额定功率、限流、纹波及损耗限值作为命名 settings 字典传递；动作范围、工况网格、SPS、PPO 训练和自定义奖励目标后续需要新声明/版本，不宣称已经迁移。原始代码一致性只验证迁移正确性，不验证硬件模型准确性。
