# 需求优先的工作流设计（首版）

## 使用路径

打开“AI 搭建工作流”，先描述目标、已有数据和限制。此时不用填写运行参数。

1. 智能体提出计算步骤、数据依赖、假设、公式和工具候选。
2. 用户查看 LaTeX 公式、输入输出声明、代码和选择依据；必要时修改并保存为方案新版本。
3. 用户明确确认候选工具及未验证状态。缺工具时，方案停在“等待补齐工具”，不会生成假节点。
4. 为缺失步骤提供公式或上传一个函数，说明变量含义、单位和依据；可填写独立数值样例。
5. 平台检查受控语法、接口、样例；用户确认后工具独立注册，派生新方案继续。
6. DSH 只提交接线候选。平台检查模块版本、声明、连线和控制结构；检查通过后用户保存新工作流。
7. 从画布进入实际输入配置和运行。保存时不要求数值，不伪造一次成功运行。

“先上传工具”入口也不依赖现有节点：分析上传函数形成单工具方案，核对声明后生成适配候选并独立注册；不必继续拼成整机工作流。声明编辑是结构化表单，用户无需编写 JSON。新增字段表单首版提供数值字段；已有数组声明保持原样，更复杂声明由需求和集中澄清提供。

旧的固定 DBSRC 运行对照入口保留在折叠区，原有 59 项输入配置仅在那里或实际运行时使用。

## 后端分工

- 模型定义：`backend/pe_workflow/models.py` 中 DesignPlan、DesignStep、DesignRequest 和 FormulaRequest。
- 状态机：`backend/pe_workflow/designs.py`。
- 方案存储：本机 SQLite 的 workflow_designs；带乐观版本检查和事件时间线。
- 工具目录快照按内容指纹保存到 contexts，避免每次状态变更重复写入整个库。
- DSH 配置：`dsh/preset/flux-design/`（安装名 flux-design-v2）。工具只有 design_context、design_module、design_result；不能直接发布。
- 桥接：`bridge/flux_worker_client.py`，限定任务与调用凭证。
- 已注册模块的完整接口由平台物化，禁止模型修改已声明的类型、单位和语义。
- 候选公式的独立预期答案不发送给智能体；仅平台使用用户提供的答案进行比较。
- 每阶段首次生成加最多三次修正；同类错误连续两次停止。用户可批准追加。送达不明不自动重发，停止后的晚到回传不应用。

## 检查结果的含义

“结构检查通过”只表示模块存在、接口与连线可编译，不能证明物理计算路径正确。
“样例通过”只表示用户提供的样例通过，不表示公式在所有工况正确。
没有独立样例时可以保存、注册为待核对工具；在本版中所有候选都要求用户明确核对选用，不将现有工具库假定为经过科学认证。

公式的转置、重采样、周期截取等仍必须显式声明，且至少两个独立验证样例。样例表单可逐组添加独立输入输出，复杂数组变换还须人工核对适用前提。

## 环境包接口

请求预留 environment_ref 和 allow_external_suggestions；上下文返回 environment_package_v1 接口标识与 not_installed 状态。目前不接受伪造的已安装包引用。关闭包外建议时，DSH 只应参考用户说明和注册模块声明；这是可审查的规划约束，尚无通用领域知识规则引擎证明物理链完整性。

## 验收与限制

自动化集成测试以模拟 DSH 回传覆盖完整链路、缺工具恢复、公式错误拦截、版本派生、未知环境包、凭证和晚到回传。真实 DSH 单独验收，不能拿模拟测试替代真实模型表现。

当前不包含环境包编辑器、任意拓扑知识推理、自动器件选型、PPO 训练，也不将所有用户需求保证为可规划。生成结果仍需要用户确认，缺少依据时应明确停止。

## 安装新 DSH 预设

仅安装本功能的预设，避免改动已有代理：

```powershell
.venv/Scripts/python.exe scripts/install_dsh_presets.py --only flux-design
```

安装名为 `flux-design-v2`，项目内源码仍在 `dsh/preset/flux-design`。平台会核对预设和上下文提供程序指纹；修改后需核对新配置再继续，旧配置会保留。桥接使用项目 data/dsh-inbox 中的短期 JSON 文件，解决 Windows 命令行长参数限制；文件读后清理，不进入版本库。

## 字段依赖门禁

公式候选增加字段读取审核、接口冻结、最小输入及无关携带字段测试。检查范围与限制见 [模块依赖决策](decisions-module-dependencies.md)。任意 LaTeX 不是可靠依赖证明，代码动态访问不自动放行。
