## 已实现

- 给智能体提供缺失字段、兼容来源候选、接口派生修改要求，禁止跨来源字段映射和伪造上游字段。
- 给出保护条件在节点局部接口内的精确路径候选，不自动选定物理角色。
- 用具体诊断代码与路径计算重复错误，避免不同预检查错误被误算为同类重复。
- 同一需求的重新规划校验原保护条件是否丢失；按明确接线归一化字段路径。受保护步骤改名或删除条件均不能直接通过。

## 结论与后续边界

平台能够安全发现并阻止这类错误，但“DSH 根据诊断自动完成修复”的真实闭环仍未通过，不能用单元测试通过代替真实验证成功。

上述两次失败后，已实现有严格操作类型和目标步骤 ID 的[局部修复补丁协议](plan-patch-protocol.md)。平台冻结已有步骤身份和保护条件，智能体只提出被允许的接口、来源映射修改；保护条件只按明确映射翻译，无法唯一对应时追问。不得通过增加提示词、放宽校验或无限追加机会来宣称完成。补丁协议的真实测试记录另行追加，不改变本节两次完整重写测试失败的结论。
