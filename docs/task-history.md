# 测试任务归档与重新测试

历史方案属于任务记录，不等于已保存工作流或已注册工具。归档只改变任务可见性并暂停关联工具补齐队列；不删除候选、调用预算、诊断、模块或已保存工作流。

主任务列表默认排除归档记录。逐节点工具生成子任务收纳在原方案的补齐队列内，不再逐条占据主任务选择框。直接读取原任务编号仍可查看记录。

在“历史方案与任务管理”中勾选“查看已归档任务”，可查看旧记录并恢复相关任务及队列。恢复队列保持暂停，不自动调用模型。执行中或调用送达不明的记录不能直接归档或恢复，需要先核对状态。

用户明确要求重新测试时，可以建立独立测试方案：保留旧测试在归档中，显示新测试身份，重新核对方案与调用上限，不把旧任务恢复伪装成预算重置。新任务不携带旧候选、失败计数或自动运行指令。

本次同步 Buck 清理将 39 条旧任务和 3 个补齐队列归档，任务与队列原文另外导出到本机 `data/archives/` 下的压缩 JSON。主列表保留一条新的 12 节点方案，处于方案待确认状态，模型调用为 0。原有 8 项缺失语义仅从原字段说明复制为待核对草案；用户确认新方案后才可用于生成。
