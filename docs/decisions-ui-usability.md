# 前端易用性决策与验收

## 已确认的决定

- 主要用户为懂电力电子、不了解 JSON 与平台内部结构的研究人员。理由：不能要求用户先理解实现细节。
- 首页按任务引导；侧栏保留工作流库、工具库和画布入口。理由：兼顾首次使用与熟练操作。
- 三条路径同时整理：运行已有流程、自然语言建图、独立上传工具。理由：避免只改善入口、后续仍无法操作。
- 建图先确认方案，运行时再填数值；代码、适配声明、配置及记录按需展开。关键适用前提与澄清问题直接显示。
- 节点详情使用右侧面板，保持画布可见；字段默认按独立字典分组，保留名称、单位和来源，支持缺失项筛选。
- 结果优先展示输出指标与单位；完整字典、数组和技术追踪保留。执行成功不能自动解释为工程可行。
- 工具以家族收纳版本与派生关系；当前流程锁定具体版本，禁止自动升级。
- 错误先说明问题和处理动作，保留原始诊断供检查。保存失败不宣称保存成功。
- 可审查入口始终存在，不采用全局简单/专家模式开关。理由：用户可直接找到当前操作的依据。

## 验收任务（待真实新用户执行）

不提供口头指导，只允许页面内帮助。测试者应是未使用过平台的同学。

1. 从首页找到一个已有电容损耗流程，打开输入，核对 F、Hz、A，填写并运行，找到损耗及单位。
2. 新建 AI 建图任务，描述单组电容损耗目标，核对步骤与适用条件，确认搭建并保存；不得先要求填写旧版 59 项参数。
3. 不选中节点，使用“上传计算工具”入口提供一个单函数，完成声明、样例、候选检查和注册。
4. 分别观察缺少输入、语义不清、候选验证失败的处理入口，说明下一步如何操作。

记录：步骤、预期动作、实际动作、停顿或误解、是否求助、修改建议。开发者浏览器自测不能替代此验收。

## 本次改版边界

不修改科学计算公式、DSH 调用策略、注册校验、发布权限或已有工作流数据。此次重点为导航与信息层级，完整领域环境包和 PPO 不在范围内。
