# AI 建图常用输入配置

默认值是明确来源和适用条件下可重复使用的一组设置，不代表平台能猜出未知物理参数。当前建图复用旧 DBSRC 的完整字典契约，器件体积、成本等字段仍需传入；本次没有修改不可变计算模块，也没有将这些字段伪造为零。

使用：打开 AI 搭建工作流。第一次可载入整套平台示例（会替换当前输入，保留已写计算目标，明确为演示数据），或自行填写真实参数。在“将当前输入保存为常用配置”填写名称及适用条件/来源后保存。以后选择配置并点击“只补齐空缺参数”，通常只需核对本次工况和设计。其余器件及旧模型字典默认折叠，完整字段仍可展开检查。

配置是本机独立快照，允许只保存部分有效输入，不自动应用或共享。已有值、零值、既有来源和已选条件不会被覆盖。空白数值不按零保存。应用的每个字段记录配置来源；最终任务冻结具体数值及来源，不依赖以后可能改变的默认设置。声明或场景变化会阻止旧配置直接应用。

提交前先检查必填字段，不为明显缺失的输入启动模型调用。数值与目标文字冲突、语义和物理条件仍由已有校验处理。示例不是器件实测或工程合格依据，配置名称也不构成审核认证。

验证：相关后端 44 项通过，前端构建通过。本轮不调用真实 DSH、不改变公式和旧任务。本机保存配置位于工作台 SQLite 的 assembly_input_profiles 表，不提交源码或公开上传。

实际页面验收：载入明确标记的平台示例并保存为“平台示例 · DBSRC 起始值（待核对）”；关闭再打开后，配置可选但输入仍为空。先手填 Vout=400 V，再点击补齐，58 个空缺参数被补齐、1 个已有值保留，Vout 仍为 400 V，其余 5 个字典缺失项为 0。没有发起 DSH 调用。
