# 项目输入配置文件

项目随附 `resources/input-profiles/dbsrc-eps-baseline-v1.json`，包含当前 AI 建图支持的全部 59 项输入、5 项场景条件，以及逐字段的中文名称、旧契约单位、命名表引用和数值来源。

## 使用

1. 打开 AI 新建工作流。
2. 在常用输入配置中选择 `[配置文件] 文件配置 · DBSRC EPS 基准输入 v1（待核对）`。
3. 点击“只补齐空缺参数”。已有值（包括 0）不会被覆盖。
4. 核对本次设计、工况、目标和条件，再提交生成。

直接修改 JSON 的 `inputs` 可以制作本项目的输入方案；修改 `name`、`notes` 记录适用条件。保存后重新打开窗口。文件随源代码和便携包一起分发；本机保存的常用配置仍独立存放于 SQLite。

## 来源和边界

声明参考团队对齐表 `resources/parameter_dictionary-v1.csv`，数值来自冻结 WDY 旧程序生成的现有平台示例。词典不是默认数值表。`parameter_declarations` 的字典引用用于查阅，没有更改已注册模块的字段名。

`runtime_unit` 必须保持模块原契约；部分旧字段未声明单位，而词典声明了单位，这些项标记为 `name_reference_unit_requires_review`，不会自动换算。`valid`、`reason`、`vi/pi` 等控制字段保留为项目内部声明。

设计、电感电容、频率与器件相互有关，修改后不会自动重新选型或重算所有派生参数。零成本、旧有效性标志等基准值不代表真实器件。此配置仅用于现有 EPS 单工况有限候选损耗链，不构成工程可行性证明。

加载时校验 JSON、全部必填字段、类型、单位、契约指纹、场景版本和词典文件指纹。失配配置禁用；不能靠修改指纹绕过工程核对。
