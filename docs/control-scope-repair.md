# 循环与子图来源修订

有限 batch 的 rows 在顶层读取整张网格；循环体只读取当前行 `item`、显式 captures 和同一子图成员输出。内部步骤不得把外部网格加入依赖来绕过作用域。

预检查先集中收集作用域错误，再检查端口、字段和依赖。诊断携带具体输入位置、原绑定、当前作用域、可用内部节点和共享输入；作用域变更进入人工确认，不消耗模型调用逐个补依赖。

来源预览仅在以下条件同时满足时提出修改：输入明确命名为 item；绑定恰为所在循环的 rows 来源；没有标量提取；当前行契约与目标字典兼容。保留字段映射，不推断新字段或物理语义。不满足条件的来源不自动修正。

用户确认预览后派生新方案，移除因来源变化失效的外部依赖，保留其他声明、公式、输入输出、单位和保护条件。复用原预算、重复错误计数及历史；不调用模型，不注册、不运行。预览使用修订号和内容哈希防止过时确认，重复提交幂等。

本次 Flyback 原方案只读检查发现 5 处错误来源、2 处过时依赖；建议差异后的结构预检查通过。原任务未被自动应用，仍由用户在页面确认。不代表工具实现、数值或工程适用性已通过。

验收：全量首次运行 515 通过、2 失败（旧恢复测试前提过时和缺失字段诊断被遮蔽）；修复后二者及循环/来源/规划/提交协议相关测试 40 项全部通过。前端测试与生产构建通过。运行平台 GET 预览确认 5 处来源、2 处依赖、结构预检通过，任务仍为 3/4 次；未执行 POST 确认，未调用 DSH。
