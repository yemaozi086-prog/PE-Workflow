# 工作流日常操作改造计划

状态：Q91–Q96 已由用户选择全部 A；本文件为待确认实施计划，尚未开始本轮功能开发。沿用现有技术栈、不可变模块版本和冻结计算快照。

## 目标与验收闭环

研究人员无需编写 JSON，即可从已有方案复制或创建流程、修改带单位参数、保存草稿、运行、查看结果、删除到回收站并恢复。JSON 仍是平台内部协议与可选高级视图，不取消或另造计算接口。

## 1. 工作流管理与草稿

- 将小加号改为明显“新建工作流”按钮；向导包含复制已有流程、从模板创建、AI 辅助搭建、空白画布。空白画布不预塞无意义的 x 参数。
- 列表每项提供重命名、复制、移入回收站；列表独立滚动、搜索，回收站单独入口。
- 复制新建独立 ID，复制选定内容、输入、布局及固定模块引用；记录源 workflow/revision 或草稿快照哈希。明确选择当前草稿还是已保存版本，不复制计算历史，也不默认升级模块。
- 工作流身份/显示名称/归档状态/复制来源属于管理元数据，不为重命名而改写旧版本、旧任务或运行名称。
- SQLite 增加管理元数据和独立草稿记录。草稿带 draft_revision、base_revision 和更新时间，与已保存工作流 revision 分开；旧数据迁移和所有发布入口兼容。
- 输入、接线和布局修改后短暂防抖自动保存草稿；草稿允许缺失/非法数值，以便恢复未完成编辑，执行前严格校验。不能把空白转成 0，也不能因即时校验失败丢掉用户文字。
- 显示草稿保存中、已保存、失败；切换或关闭时保存未成功则保留恢复副本并明确提示。多个标签页用乐观锁避免覆盖，冲突时提供比较/另存副本。大数组不得无提示塞入 localStorage，恢复存储失败要报告。
- “保存为版本”创建不可变版本；保存成功不等于计算通过。草稿状态、已保存版本、当前内容的验证/运行状态分别展示，计算相关改动使旧结果标记为历史结果。
- 回收站可恢复，不物理删除版本、运行、任务和共享模块。归档目标不能被晚到适配任务悄悄重新发布；归档/发布并发必须在提交时检查。首次不提供永久清空。

## 2. 声明驱动的编辑器

- 输入和常量统一使用一个编辑器，覆盖工作流输入、节点字典常量及 AI 建图输入；模块外部仍是独立命名的扁平字典。
- 显示中文名、原字段名、含义、单位、必填状态、当前值和来源；从现有 Port、词典及显示元数据读取。声明缺失就显示原名和“说明待补”，不让模型臆造专业名称或物理含义。
- 数字输入、布尔开关、普通文本。下拉选项仅来自明确的可选值声明；现有 Port 没有通用 enum，不从字符串字段名猜出选项。
- 字典按名称折叠，可查看完整字段；来源区分用户、所选模板/复制来源、待核对的自然语言提取值、缺失值。
- 首版数组支持一维/二维表格、粘贴表格与 CSV 导入。导入前显示列映射、预期形状/单位/坐标、错误位置；不猜单位、不自动转置或重采样。更高维数组提供显式形状和切片查看/编辑，或标明当前表单能力缺口；不强迫用户回去手写 JSON，也不承诺完成通用科学数据编辑器。
- 表单校验服务于即时提示，后台契约/单位/轴/来源校验仍是执行依据；不能只依赖前端检查。
- 空白画布提供声明向导：选择词典参数或人工填写名称、语义、类型、单位/数组维度；不依赖 JSON 创建输入字典或输出绑定。自定义物理语义必须有声明，必要时沿用独立定义注册流程。

## 3. AI 建图向导

- 页面顺序：说明目标 → 核对支持场景及提取条件 → 填写/带入输入 → 集中补充 → 生成、验证和查看。
- 条件使用中文选项/确认项，输入使用同一声明编辑器。示例输入只通过明确“使用示例”操作带入，并保留示例来源与待核对标记。
- 自然语言数值提取只是待核对建议；必须显示目标字段、值、单位和原文依据。文本与表单不一致时提示冲突，不静默选择其中之一。
- 配置、方案、真实验证、事件日志、停止及修正上限仍保留；日常界面用摘要/状态展示，完整 JSON、提示词和日志按需展开。
- 当前仍只开放已经验收的 DBSRC EPS 候选电流到电容损耗场景。本轮不扩充任意拓扑规划，不写 DAB，不改变 DSH 发布权限。

## 实施顺序

1. 管理元数据、草稿/回收站/复制 API 及迁移；处理发布并发，保护已有工作流和运行快照。
2. 新建向导、列表操作、草稿状态和切换恢复。
3. 统一声明编辑器，接入输入、常量和空白画布声明；数组导入与即时错误反馈。
4. 改造 AI 建图向导，连接已有调度器，核对参数来源与文本冲突。

实施前备份源码和 SQLite；按阶段验证后继续，不能只交付按钮或静态样式。

## 验收任务

- 完全不打开 JSON：复制已保存 DBSRC 方案，命名并改工况，切换返回/刷新恢复草稿，运行新方案；源流程、固定模块版本和源运行结果不变。
- 从空白画布通过声明向导添加字典输入、模块和输出绑定并运行一个简单链；不自动填入未知物理量。
- 删除副本后从回收站恢复，版本/草稿/运行可追溯；删除不影响原流程或共享模块。晚到任务不能复活已归档目标。
- 输入空值或非法数值不会变成 0，草稿可恢复但不能执行；多标签页冲突不静默覆盖。
- 一维波形表格/CSV 导入成功；错误维度、坐标、单位和列映射有具体诊断，不隐式变换。
- 通过表单提交已支持的 AI 场景并查看已有真实验收任务；只在新增行为需要时做真实 DSH 回归，不因 UI 改造无限重复模型调用。
- 既有模块注册、版本派生、自动适配、批处理、运行快照与回放回归通过；前端构建及浏览器操作验证通过。
