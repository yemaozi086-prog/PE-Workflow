# 工作流工作空间 UI 验收（2026-10-17）

本轮在实施前保存源码与 SQLite：`backups/before-workspace-ui-20261017-005954/`（pe-workflow 项目目录下）。本轮不调用真实 DSH，也不改变公式或扩充拓扑场景。

## 已实现

- 工作流列表独立滚动、搜索、新建、重命名、独立复制、回收站恢复。复制保留输入、图结构、布局及固定模块版本，记录来源，不复制运行历史。
- 草稿与保存版本分离，800 ms 防抖保存；无效值和不完整输入可存草稿。并发版本冲突拒绝覆盖，可另存本页。IndexedDB 保存本机未提交编辑以支持恢复，异常时明确提示。
- 空白画布声明向导可以沿用模块契约、选词典或显式手工声明；输出选择已有声明来源。输入、常量、AI 建图共用声明表单。
- 数值数组提供表格、分页、CSV/粘贴导入、列选择、单位确认和高维切片编辑。新增单元格为空，不暗填零。
- AI 建图提供中文条件选项和输入表单。自然语言明确数值仅作为建议，必须确认采用；不支持的条件、单位歧义和冲突交由诊断/澄清处理。完整 JSON 作为高级视图保留。
- 归档/恢复的生命周期序号阻止晚到候选覆盖目标；运行快照与旧版本保留。
- 后台调度只加载活动任务；管理操作只刷新工作流列表及回收站，减少重复加载历史与模块库。

## 实际页面操作

1. 新建“UI验收 · 表单与草稿”模板副本，表单将 `component_request.tan_delta` 改为 0.002。后台草稿第 2 版保存为数值，正式版本仍为 0；刷新后草稿恢复。保存 r1 并运行得到两项电容损耗均为 **2.273642044169933 W**，与指定公式一致。
2. 用列表菜单复制为“UI验收 · 管理副本”，再重命名“UI验收 · 回收恢复副本”。副本起始仅草稿、结果区等待运行；移入回收站后恢复成功，回收站为空，副本重新出现在列表。首次恢复的后续全资源刷新曾显示连接失败，恢复写入本身成功；本轮随后将管理刷新缩小为列表和回收站。
3. 从空白新建“UI验收 · 空白声明”。直接采用 `component_bag@1.request` 声明，填写 200 nF、12 元、0.001；添加 component_bag v1，通过来源下拉接线，声明 component 输出。运行返回 **{C_total:200,cost:12,tan_delta:0.001}**。全过程未打开 JSON。
4. 在 AI 向导输入“输出电压 400 V，输出功率 1.5 kW”。显示两项原文建议，输入保持空；点击功率建议后才填入 point.Pout=1500 W，并显示已核对原文来源。未提交模型调用。
5. 新建“UI验收 · 数组导入”波形模板副本，粘贴电流列 0/2/4。未确认单位时拒绝导入；明确确认 A 后导入，积分结果 **0.040 J**（10 V，0–2 ms，0–4 A 线性）。将 voltage 留空运行得到 VALUE_TYPE /inputs/voltage，未按零计算；恢复 10 V 后保存 r1。

## 边界

AI 仍只开放已验证的 DBSRC EPS 单工况候选电流→电容损耗；本轮没有证明任意拓扑自动建图。部分旧模块声明缺少中文名，界面如实显示字段原名；旧波形示例仍兼容旧版裸数组接口，新建声明向导要求字典。数组是有上限的通用编辑器，不能替代科学数据分析软件。已有 DSH 真实验收结果见 assembly-real-verification.json；本轮表单改造未再次进行付费模型回归。测试工作流保留并以“UI验收”命名供检查。
