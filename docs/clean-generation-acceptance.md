## 通用机制修改

1. 循环接线不再只报告第一个字段错误：从运行时正式控制接口逐字段检查，集中收集独立问题；不猜物理来源、不自动改候选。
2. 待补齐工具的蓝图输入允许 `from_source:true` 与显式字段列表。平台复制明确来源的完整字段声明和字段映射，包含循环输出的数组形状、轴和文字精度。已注册工具仍使用冻结接口。
3. 控制协议格式错误允许哈希绑定的局部修正：无节点 ID、但端口精确命名局部输入的绑定；已明确命名 item 却写了未声明行别名；循环输出选了成员已有字段，却使用只接受完整字典的位置。每种修正均限定允许变动，不允许换生产节点或改公式。
4. 回调路由由平台按 task/call/凭证哈希绑定到 loopback 端口，模型不再选择回调服务；默认正式服务保持兼容。
5. 工具提交回执显式要求结束当前调用，仅回传诊断与额度，不回显人类独立验收答案、完整方案或配置。
6. 显式来源字段错误一次收集，并列出区分大小写的实际字段；不做大小写猜测。局部修复诊断不再重复附带整份旧候选，原文仍可通过独立分页章节查看。
7. 输入保护允许受限的 `len(字典[数组字段])` 比较，不开放一般计算函数。有限 batch 在执行任何成员前，对所有行预检查能完全由 item/共享输入确定的既有保护；依赖中间计算结果的保护仍在原节点执行，原条件不删除。
