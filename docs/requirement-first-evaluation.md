# 需求优先建图验收记录

本记录区分真实 DSH 调用、平台自动化集成测试与独立公式核对。测试公式仅为平台示例，待课题组核对。

## 真实任务一：使用已有工具

需求：使用 cr_loss_flat@1，给定组件电容、损耗角正切、开关频率、RMS 电流，计算单组与总电容损耗。不选型、不优化、不修正温度。

- 需求规划 1 次生成，得到一个计算步骤，两个外部输入字典。
- 用户确认后，接线首次错误地拆成裸参数输出；平台拦截，DSH 修正后第二次接线通过。
- 新工作流先以空输入值保存，没有为了生成工作流要求填写 59 项。
- 之后独立提供 C=1e-6 F、tanδ=0.001、fs=100000 Hz、I_rms=2 A，运行通过。
- 直接公式 P=I²tanδ/(2πfC) 得 0.006366197723675815 W，两项输出均一致。
- 原始本机任务记录保留在本机，不随源码发布。不表示器件实测精度或整机可行性。

## 真实任务二：缺工具时补充公式

需求：新建电阻铜损工具，electrical 字典含 i_rms(A)、resistance(ohm)，loss 字典输出 p_w(W)，P=I_rms²R。

独立手算样例为：

| I_rms / A | R / ohm | P / W |
|---|---|---|
| 3 | 2 | 18 |
| 4 | 0.5 | 8 |
| 0 | 2 | 0 |

预期答案只在平台保存，不发送给 DSH。工具声明来自已确认步骤，DSH 负责函数和适配器。此次暴露了返回映射空路径、输入路径缺少 inputs 根等接口语法问题；失败候选未注册。两次按连续同类错误停止规则暂停，追加经用户明确批准；原代码未手改。最终 DSH 候选通过上述 3 组独立样例，注册为 copper_loss@1；代码及适配器未手改。

注册后重新派生方案完成接线。首次子任务受到平台阶段提示串扰，返回了错误类型，已停止并修复阶段隔离；回归测试覆盖该问题。最后接线子任务 在限定 2 次调用的额度内，第 1 次接线通过。先以空输入保存新工作流，再独立输入 I=3 A、R=2 ohm，运行成功，输出 loss.p_w=18 W。原始任务与运行记录保留在本机，不随源码发布。

此案例证明缺工具补充、公式独立样例验证、注册、恢复建图与分离运行链路可用，不证明 DSH 一次生成稳定：公式阶段实际经过初始 3 次、批准追加 2 次和最后批准 1 次，效率仍需改善。

## 平台自动化验证

测试覆盖：无数值保存、缺工具恢复、公式样例不一致拦截、两步真实依赖、错误重接线、裸参数输出、显式默认值拦截、错误单位、方案版本派生、工具版本派生与关系记录、未知环境包、停止后晚到回传、配置历史、调用额度、大载荷文件传递及清理。

这些测试模拟智能体回传，用于检验平台机制；不作为真实 DSH 一次生成成功率的证据。
