# 显式来源契约输入

用于蓝图规划阶段的待补齐工具，避免重复抄写循环输出的数组类型、轴、单位和语义。它不替智能体选择物理来源，也不修改已注册工具。

```json
{
  "inputs": {
    "scan_loss": {"from_source": true, "fields": ["P_selected"]}
  },
  "input_sources": {
    "scan_loss": {"source": "node", "node": "selected_loop", "port": "loss"}
  }
}
```

平台从明确的 `selected_loop/loss` 复制 `P_selected` 的正式声明。循环成员中的标量在循环外是带 `batch_rows` 轴的数组；文字成员在循环外是 `dtype=string` 的一维数组。平台不把它们压成单值，不过滤行，不自动转换单位。

需要局部字段名时，明确写 `field_map`，方向为目标字段到来源字段；`fields` 列出目标字段名。所有名称区分大小写。省略 `fields` 表示显式消费完整字典，不表示平台猜测实际需要哪些字段。

输出和外部输入仍通过 `port_defs` 的 `ref` 声明。已注册工具必须保留冻结接口，不能用来源复制绕过版本派生。结构预检查不会证明物理适用性或数值正确性。

## 局部修正

格式修正使用原始候选哈希和允许路径。仅在有明确作用域证据时允许修复地址种类、`item` 的正式端口、循环完整字典输出，以及无效裸数组输入的来源契约引用。禁止改变来源生产节点、公式、单位定义、保护条件或验收答案；无法定位的含义仍需澄清。

来源字段错误集中返回，并附实际字段清单，不能通过大小写模糊匹配蒙混过关。局部诊断只发送所需片段；完整旧候选仍可在 `candidate` 分页章节追溯。

## 批量原始输入保护

允许标量比较、逻辑条件及 `len(bag["array_field"])` 的长度比较。不允许在保护中运行一般计算函数或数学公式。

执行有限 batch 前，平台对全部行检查能仅由 `item` 和显式共享输入确定的原有保护；发现非法输入时标明行号、成员和条件，并拒绝进入计算子图。依赖中间计算值的保护仍在原节点执行。提前检查不删除原保护、不计算候选公式，并受检查次数上限约束。
