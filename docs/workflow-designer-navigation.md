# 工作流设计器操作整理

2026-10-20：顶部当前状态与下一步面板按实际任务和队列状态导航，不自动执行生成、追加额度、注册或保存。

- 描述需求阶段不提前要求运行数值。
- 未出方案的智能体调用仍属于第1步；方案存在后才进入第2步。
- 待核对、暂停、等待补充、接口错误、接线和保存分别提供明确入口。
- 确认方案操作移出折叠详情；只有修改后才显示保存新版本按钮。
- 工具清单按状态筛选，默认隐藏已注册项；并发设置和批量修复为独立辅助区。
- 工具详情提供返回本批清单按钮；切换任务重置滚动位置。
- 暂停说明与额度直接展示；畸形字符串候选不显示对象候选的重新验证按钮。
- 小窗口不使用大块悬浮状态卡，避免遮挡内容。

验证：前端生产构建、现有输入/画布测试、18项状态导航检查；实际浏览器检查已有LLC任务的队列筛选和暂停详情。不调用模型，不注册工具，不改变原有任务记录与额度。
