# Boost 14 节点单工况演示预演包

## 演示的目标

在此前 Buck 之外，用非同步 Boost 测试需求规划、工具匹配、缺失工具补齐、多源接线、分支汇合、数值运行和约束评价。14 个计算步骤，加工作流输入和输出，共约16张画布卡片。没有寻优、工况扫描、PPO 或收敛循环。

本资料是预演准备，尚未通过 DSH 在平台实际生成或运行。不要在视频中称为“已验证全部电力电子拓扑”或“可替代仿真”。

## 文件

- `01-需求文本.md`：复制正文到“用自然语言搭建流程”的需求框。
- `02-运行输入-A.json`：基准工况的六组输入。可按照界面逐字段填写；高级 JSON 入口可使用其中的对象，不需要把文件名或 Markdown 复制进去。
- `03-独立核算样例.json`：A、B 两个有效工况的逐步预期结果；C 为 ESR 翻倍，运行完成但纹波约束失败；D、E 为应停止的非 CCM、非法电压工况。此文件是参考结果格式，不是平台工具注册或样例导入格式。
- `reference.py`：独立于 DSH 候选的标准库核算程序。对四路 RMS 另用分段三角波平方积分核对；仍然只验证本文演示公式的实现，不构成实物或仿真验证。

运行参考程序：

```powershell
.venv/Scripts/python.exe docs/demos/boost-single-point/reference.py
```

不需要第三方依赖。它重写本目录的两个 JSON 参考文件，不改平台数据库。

## 预演操作

1. 首页选择“用自然语言搭建流程”，新建任务，粘贴需求文本；数值留到运行时。
2. 先核对方案，尤其检查 Boost 的开关阻断电压使用 Vout、MOSFET/二极管 RMS 没有重复乘占空比、电容电流不是 Buck 的 delta_i/sqrt(12)。确认来源分支明确；不要接受把电阻塞进电流输出字典的错误连接。
3. 按“补齐工具”清单生成候选。已有公式、单位和假设应从方案带入；若关键语义缺失，先处理集中问题，不反复批准同一种错误。
4. 对需要登记的工具，查看实际代码，并用参考 A、B 的对应步骤结果提供独立样例。样例输入只填该工具实际读取的字段；中间量从对应上游的参考结果取得。端口名称以确认的工具声明为准，不将整份参考 JSON 直接粘贴到某个工具的样例框。缺少独立样例时保留“未验证”标签，不把结构检查当成数值正确。
5. 核对通过的候选后明确注册，返回关联的最新方案，确认拼接并保存工作流。检查输出保留主要中间量及约束结果。
6. 输入 A，点击检查与运行，对照下表；再点击一键美化布局。录屏可选择 RMS 节点展示四路分支，再选择损耗汇总节点展示汇合。
7. 将 ESR 从 0.02 改成 0.04 ohm，其余不变，重新运行。应计算成功，但 ripple_pass=0、overall_pass=0，失败原因指向纹波；不得宣称计算程序失败。

工具生成会有实际等待，第一次预演先完整走通再录制。视频如果剪掉等待，应保留“生成中”到“候选待核对”的真实阶段转换。最终生成图可能因工具端口命名而不同，验收按计算含义和依赖，不按屏幕上的英文 ID。

## 基准 A：48 V → 96 V、480 W

主要输入：fs=100000 Hz、L=0.0001 H、C=0.00047 F、ESR=0.02 ohm、R_L=0.03 ohm、R_on=0.015 ohm、Vf=0.7 V、r_d=0.01 ohm、tr=20 ns、tf=30 ns、Ta=40 degC、Rth_sw=4 K/W、Rth_d=6 K/W。界面时间字段单位为 s 时输入 2e-8、3e-8，不能填20、30。

| 检查量 | A 基准值 | ESR 翻倍后 |
|---|---:|---:|
| 占空比 | 0.5 | 不变 |
| 平均电感电流 | 10 A | 不变 |
| 电感峰峰值纹波 | 2.4 A | 不变 |
| 电感峰值／谷值 | 11.2／8.8 A | 不变 |
| MOSFET 导通损耗 | 0.7536 W | 不变 |
| 二极管损耗 | 4.0024 W | 不变 |
| 电感直流铜损 | 3.0144 W | 不变 |
| 输出电容 ESR 损耗 | 0.5048 W | 1.0096 W |
| MOSFET 交叠开关损耗 | 2.4576 W | 不变 |
| 五项损耗总和 | 10.7328 W | 11.2376 W |
| 估算效率 | 97.81290348% | 97.71239009% |
| 纹波估计上界 | 0.27719149 V | 0.50119149 V |

纹波上限0.3 V，峰值电流上限15 A，温度上限100 degC，效率估计下限0.95，MOSFET/二极管额定电压均150 V，最小额定/理想阻断电压比1.2。裕量比均为1.5625，不含寄生过冲。

## 公式依据与适用范围

基础 Boost CCM 工作点、电感纹波和输出电容估算可参考 TI 的 [SLVA372D 应用笔记](https://www.ti.com/lit/an/slva372d/slva372d.pdf)。该文也讨论效率修正；本演示明确取理想电流关系，计算出的损耗不反馈到占空比，不能混入另一套效率修正公式。

RMS 由本演示分段三角波假设积分得到；二极管采用阈值压降加动态电阻模型，开关损耗采用指定线性交叠模型，温度采用固定结到环境等效热阻。它们是此次用户提供的明确演示要求，不是声称 TI 文档验证了整套14节点模型。独立样例验证的是实现与这些要求一致，不证明硬件精度。
