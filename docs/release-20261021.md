# 2026-10-21 交付记录

交付 Power Electronics Workflow 研究原型的当前源码与 Windows x64 自包含运行包。核心计算可以离线运行；自然语言生成需要另外安装和配置 DSH，运行包不包含 DSH 或模型凭据。

## 使用

下载 Release 中的 ZIP，核对相邻 SHA256 文件，解压后双击 Start.cmd。默认在本机 8020 端口启动，首次创建全新数据库。若要保留原机器任务，需另行备份 data/workbench.sqlite 及配置；GitHub 上不提供私人运行历史。

源码工具链固定 Python 3.14.3、Node 24.14.0、npm 11.9.0；首次执行 scripts/setup.ps1，然后 scripts/start.ps1。便携包日常启动不需要 Node。

## 包含的主要变化

需求优先的方案设计、工具补齐与并发队列、分阶段检查、单层有限网格/batch 子图、完整字符串结果、缺失推荐结果的显式处理、候选原始回执、局部修正及恢复入口。画布提供自动排布、线路优化和公式显示。

循环接口按冻结注册模块声明先解析，再处理下游来源派生，避免将平台未解析的问题误发成用户需要提供内部连接路径。
