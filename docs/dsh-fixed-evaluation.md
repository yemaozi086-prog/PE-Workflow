# 固定真实 DSH 评测

每轮三个任务，各运行一次，按 A → B → C 顺序执行，不追加修正预算、不补充 C 的答案、不人工改候选。A 为清晰的嵌套参数和混合单位上传函数；B 为原 v1 的温度公式修改及独立 thermal 字典；C 为返回单位和最终倍率未确认的函数。

A 必须发布且完整结果与独立解析计算相符。B 必须发布且三个温度下的完整矩阵、奖励等输出与原 ENV 扩展参考相符。C 必须集中追问返回单位或倍率，或明确停止，且没有发布工作流或新增模块版本。语义猜测即使数值碰巧相符也不算通过。

首次调用正确完成要求 `generation_count=1`；最终完成要求没有追加批次且调用数不超过 4。清晰任务的首轮通过率、最终完成率与 C 的正确处理分别统计。数据仅有三个开发样例，不代表统计稳定的工业成功率。

执行入口：`.venv/Scripts/python.exe scripts/run_dsh_evaluation.py freeze`、`start-next`、`report`。freeze 保存固定请求、参考及后端/工具/preset/执行器哈希。每次提交和报告都核对哈希，不允许在同一轮内修改运行逻辑。运行状态另存 state.json；原请求和 manifest 不改写。若平台故障，保留失败记录，修复后使用新轮次标识；旧报告存放各自 round 目录。

报告 `docs/dsh-fixed-evaluation.json` 为当前轮摘要；完整冻结证据在 `data/evaluations/<round_id>/`。模型只读取目标任务上下文，评分参考不通过新工具提供给模型；既有模块独立样例仍按原任务协议供实现者理解目标。公式系数与参考继续标注待课题组核对。
