# 模块字段依赖与接口冻结

## 用户确认的边界

- 接口增加、单位改变、可选变必填等变化，必须派生方案并由用户确认。代码修正不能隐式改变接口。
- 无法可靠分析的依赖保存为候选并集中追问，解决前不得自动注册和应用。
- 用 Buck 的正常与故意错误案例验收；不只检查正常运行。

## 当前实现

以已确认步骤的 Port 声明为接口依据。字段必填性形成必需/可选清单；独立 AST 分析从候选源码与显式适配器提取实际读取字段，结果记录在 dependency_audit 中。

支持：受控表达式、compute(inputs) 兼容函数、带显式适配器的单函数；字面量字典路径、简单字典别名、显式 in 分支保护，以及带明确缺省的 get 访问（执行语法仍由原有受控运行器另行检查）。标量适配器在函数调用前就会提取参数，因此不能把函数内部保护误当作适配器安全。

- 未读取的必需字段、未声明字段读取、无保护读取可选字段：停止本轮，不自动继续消耗调用，保存候选与具体字段诊断。
- 动态字段和不支持的数据流：集中追问；仍无法明确时保持受阻。
- required/default、字段集合、类型、单位等改变：要求先派生接口方案，禁止候选自己修改。
- 静态检查通过且有独立样例：按独立预期答案执行；再仅提供必需字段运行，检查能否完成；在这个最小输入上增加无关携带字段，检查输出不变。有实际作用的可选字段省略后可采用已声明默认值，其输出不必与原样例相同。
- 没有独立样例：不执行数值和输入变体测试，报告明确记为 not_run_no_independent_examples，不能宣称已运行验证。
- 注册时再次检查依赖，旧候选不会因为缺少这层审核而绕过门禁。

## 重要限制

这是受限语法的字段读取一致性审核，不是通用程序证明、数学模型证明或电路设计认证。读取了某字段，不等于证明它真正影响最终结果；两个执行样例也不能覆盖所有分支。

LaTeX 仅用于展示；本版没有把任意自然语言或 LaTeX 自动解析成可信依赖。方案阶段仍由用户确认声明；独立的代码读取检查发生在候选返回后。因此不能保证新方案第一次生成就完全正确，但这类接口问题不应再无解释地消耗多轮修正。

已有工具库未进行批量重新认证；本门禁先覆盖“从需求设计工作流”中的新工具/公式候选。旧上传替换路径仍使用原验证流程，不能把本次覆盖范围说成全平台已统一。

## Buck 验收

受限模型：理想、稳态 CCM、忽略 ESR 和寄生参数，不代表器件实验验证。

- 电流节点：D=Vout/Vin，delta_i=(Vin-Vout)*D/(L*fs)。
- 电压节点：delta_v=delta_i/(8*fs*C)，最小输入只有 C、fs、delta_i。
- 24 V→12 V、100 kHz、L=100 μH、C=100 μF：delta_i=0.6 A，delta_v=7.5 mV。
- L 改为 200 μH：delta_v=3.75 mV。
- 多余必填 L、漏声明读取、无保护读取可选字段、动态键以及偷偷改 required：分别测试拦截/澄清，确保未注册，原候选保存。

这些是开发测试夹具与真实执行引擎测试，不是本次真实 DSH 建图成功记录；未额外调用 DSH 或改变用户 Buck 方案。
