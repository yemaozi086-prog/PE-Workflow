# 工具并发生成与公式展示

## 使用

“补齐计算工具”可设置同时生成数量 1–10，默认 2。已有队列可通过“本批并发数量 → 应用并发数（不追加额度）”调整。旧队列未记录配置时保持串行。平台全部任务合计最多 10 个在途调用；实际速度还取决于模型服务并发和限流。

每一步使用独立会话和原有调用额度。调低并发不会撤回已发出的调用；暂停后不再发送新调用。送达不明的调用继续占用名额，避免重复发送。队列公平轮转，使用锁及修订检查防止重复调度。检查通过后仍需用户明确注册，不自动运行工作流。本实现针对当前单服务进程部署。

点击画布节点，可查看来自本工作流确认方案或该工具注册方案的 LaTeX 公式、来源与原文，实际代码仍可展开。工具库版本详情同样展示注册公式。元数据只读关联精确版本，不改写已注册模块或其哈希；无可追溯公式时明确提示，不从代码猜公式。公式展示不代表数学等价或工程正确性验证。

## 验证

- 后端完整回归：368 项通过。
- 前端测试及生产构建通过。
- 隔离数据库、关闭模型调用的页面验收：并发可改为 10，调用数保持 0；Boost RMS 公式实际渲染且分行显示。
- 调度测试覆盖全局上限、队列公平性、暂停、降低并发、额度不变、送达不明及重复调度。
